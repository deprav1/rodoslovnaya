# 🌿 Хроники двух родов: Семёновы и Женцовы

Интерактивный генеалогический портал и результаты архивных исследований семей Дениса Семёнова и Маргариты Женцовой.

## 🌐 Онлайн-версия
Сайт опубликован на GitHub Pages: **[Открыть интерактивное древо](https://deprav1.github.io/rodoslovnaya/)**

## 📁 Структура проекта
* `index.html` — Главный интерактивный веб-портал с карточками-досье, умными фильтрами, летописями и картой.
* `00_НАЧНИ_ОТСЮДА.html` — Сводное оглавление со всеми отчётами.
* `01_Древо_наглядное.html` — Полная наглядная схема древа с линиями родства.
* `02_Отчёт_исследования.html` — Досье семьи Дениса (Кострома, Омск, Беларусь).
* `03_Древо_схема_поколений.html` — Схема по поколениям.
* `04_Отчёт_Женцовы.html` — Досье семьи Маргариты (Тверь, Харбин, Харьков).
* `05_План_поиска.html` — План архивного поиска по линии Ливенси и Токмаковых.
* `06_Анкета_для_родных.html` — Опросник для родственников.
* `07_Исходное_древо_MyHeritage.ged` — Мастер-файл GEDCOM 5.5.1 со всеми 40+ персонами.
* `08_План_поиска_Семёновы.html` — План поиска по линии Семёновых, Нечаевых и Карпущенко.
* `09_Вопросы_деду.html` — Руководство для интервью с дедушкой Иваном Васильевичем (84 года).
