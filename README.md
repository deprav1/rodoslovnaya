# 🌿 Хроники двух родов: Семёновы и Женцовы

Интерактивный генеалогический портал и результаты архивных исследований семей **Дениса Семёнова** и **Маргариты Женцовой**.

## 🌐 Онлайн-версия
Сайт опубликован на GitHub Pages: **[Открыть интерактивное древо](https://deprav1.github.io/rodoslovnaya/)**

## 📁 Структура проекта
* `index.html` — Главный интерактивный веб-портал с карточками-досье, умными фильтрами, летописями, библиотекой источников и шаблонами запросов.
* `Запросы_в_архив_и_ЗАГС.md` — Полный пакет готовых официальных заявлений в ЗАГС (Омск, Новосибирск, Называевск), архив ГИАОО и Посольство РФ в Венгрии.
* `07_Исходное_древо_MyHeritage.ged` — Мастер-файл GEDCOM 5.5.1 со всеми 45 персонами древа, семейными связями и архивными примечаниями.
* `00_НАЧНИ_ОТСЮДА.html` — Сводное оглавление со всеми отчётами.
* `01_Древо_наглядное.html` — Наглядная схема древа с линиями родства.
* `02_Отчёт_исследования.html` — Досье семьи Дениса (Кострома, Омск, Беларусь).
* `03_Древо_схема_поколений.html` — Схема по поколениям.
* `04_Отчёт_Женцовы.html` — Досье семьи Маргариты (Тверь, Харбин, Харьков).
* `05_План_поиска.html` — План архивного поиска по линии Ливенси и Токмаковых.
* `06_Анкета_для_родных.html` — Опросник для родственников.
* `08_План_поиска_Семёновы.html` — План поиска по линии Семёновых, Нечаевых и Карпущенко.
* `09_Вопросы_деду.html` — Руководство для интервью с дедушкой Иваном Васильевичем Нечаевым (84 года).
* `10_План_и_протокол_исследования.html` — Методология и архивный протокол исследования.
* `11_Шаблоны_запросов_в_архивы.html` — Веб-версия шаблонов для печати.
* `docs/research/2026-08-17-confirmed-tree.md` — Каноническая версия: только подтверждённые персональные факты и незамкнутые связи.
* `docs/research/2026-08-17-critical-evidence-audit.md` — Аудит всех 17 семей GEDCOM с уровнями доказательности.
* `docs/research/2026-08-17-primary-source-ledger.md` — Реестр первичных военных и архивных источников с точными шифрами.
* `docs/research/2026-08-17-semyonov-focus.md` — Отдельное досье по линии Семёновых и отрицательным результатам открытого поиска.
* `docs/research/2026-08-17-full-genealogy-dossier.md` — Академическое досье исследования по всем 7 родам.
* `docs/solutions/` — Инженерная база знаний и решения генеалогических тупиков.
